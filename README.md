# Willage_Client

Klient a prototypy terénu pro hru Willage (Godot 4.7.2, Compatibility renderer).

- `godot-prototyp/` – hlavní prototyp ostrova (bloky 16 × 16 × 64 buněk, buňka 1 × 1 × 0,5).
- `skala-studie/` – studie skály (Surface Nets, kopání po chuncích, C# benchmark).
- `trava-studie/` – studie trávy a vegetace (trsy C, procedurální louka, dráha kroků, vítr).
- `napojeni-studie/` – studie napojení terénu (duální mřížka, písek, břeh, voda).
- `DENIK.md` – vývojový deník: A použité směry, B zamítnuté směry, C návrhy optimalizací.

Videa (`*.mp4`) a buildy nejsou v repu kvůli velikosti.
